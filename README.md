# 🍎 Fruit Classifier using Deep Learning

## 📌 Overview
This project is a deep learning-based Fruit Classifier that identifies different types of fruits from images using TensorFlow/Keras.

## 🚀 Features
- Classifies multiple fruit categories
- Image preprocessing
- Model training using CNN
- Predicts fruit from a new image
- Displays prediction confidence

## 🛠️ Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- OpenCV
- Matplotlib

## 📂 Project Structure
```
dataset/
train.py
predict.py
fruit_model.h5
test.png
README.md
```

## ▶️ How to Run
1. Install the required libraries.
2. Run `train.py` to train the model.
3. Run `predict.py` to classify a new fruit image.

## 📊 Output
The model predicts the fruit name along with its confidence score.
